## 🎯 Обзор проекта

**ValutaTrade Hub** позволяет пользователям:

- 📝 Регистрироваться и управлять учетными записями
- 💰 Создавать и управлять виртуальным портфелем фиатных и криптовалют
- 💱 Совершать сделки по покупке/продаже валют
- 📊 Отслеживать актуальные курсы в реальном времени
- 📈 Просматривать историю операций и текущую стоимость портфеля

### Основные компоненты системы

Система состоит из двух основных сервисов:

- **Core Service** — основное приложение с пользовательским интерфейсом (CLI)
- **Parser Service** — сервис для получения актуальных курсов валют из внешних API

## 🚀 Установка и запуск

### Предварительные требования

- Python 3.8 или выше
- Poetry (менеджер зависимостей)

### Пошаговая установка

1. **Клонируйте репозиторий и перейдите в папку проекта:**

```bash
cd finalproject_Pozdnyakov_Egor_M25_555
```

2. **Установите зависимости:**

```bash
make install
```

3. **Настройте API ключи (опционально):**

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env файл, добавив ваш API ключ
```

### Запуск приложения

**Основной способ:**

```bash
make project
```

**Альтернативные способы:**

```bash
poetry run python3 main.py
# или
poetry run project
```

## 🏗 Архитектура

### Модели данных

#### User (Пользователь)

- Приватные атрибуты с геттерами/сеттерами
- Хеширование паролей с солью (SHA-256)
- Валидация: имя не пустое, пароль ≥ 4 символов

#### Wallet (Кошелек)

- Баланс с защитой от отрицательных значений
- Операции `deposit`/`withdraw` с валидацией
- Автоматическая проверка достаточности средств

#### Portfolio (Портфель)

- Управление несколькими кошельками
- Расчет общей стоимости в базовой валюте
- Автоматическое создание кошельков при первой покупке

### Система сессии

**Особенности:**

- Автоматическое сохранение состояния входа между командами
- Файл `data/session.json` для хранения ID текущего пользователя
- Автозагрузка сессии при запуске приложения
- Безопасный выход с очисткой сессии

### Парсер курсов

**Поддерживаемые API:**

- **CoinGecko** — для криптовалют (BTC, ETH, SOL и др.)
- **ExchangeRate-API** — для фиатных валют (USD, EUR, GBP и др.)

**Функциональность:**

- Кэширование курсов с TTL (5 минут по умолчанию)
- Отказоустойчивость (работа при недоступности API)
- Историческое хранение данных
- Автоматическое обновление по расписанию

### Логирование

**Настройки:**

- Ротация логов (10MB макс. размер, 5 файлов)
- Форматирование с временными метками
- Уровень логирования: INFO
- Отдельные логи для действий пользователя

**Логируемые операции:**

- Регистрация и вход пользователей
- Покупка и продажа валют
- Обновление курсов
- Ошибки и исключения
